# Requisitos Funcionais (MedScheduler)
1. O sistema deve permitir que pacientes agendem consultas online.
2. O sistema deve enviar lembretes por WhatsApp 24h antes da consulta.
3. O sistema deve permitir que médicos visualizem sua agenda diária.
4. O sistema deve permitir que pacientes cancelem consultas com até 24h de antecedência.
