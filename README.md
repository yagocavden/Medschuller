# MedScheduler: Sistema de Agendamento Inteligente
## Sobre o Projeto
O MedScheduler é uma plataforma desenvolvida para otimizar o agendamento de consultas na Clínica Vitalis, reduzindo a taxa de faltas (no-shows)
e automatizando a comunicação com os pacientes.
## Objetivos Principais
- Reduzir a taxa de faltas de 25% para menos de 10%.
- Automatizar o envio de lembretes via WhatsApp e e-mail.
- Otimizar a ocupação da agenda dos médicos.
